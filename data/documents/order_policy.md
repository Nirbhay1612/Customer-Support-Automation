# Order Policy

## Order Status

Customers can request information about their order status using their order ID.

## Order Tracking

Tracking information should only be provided when it is available from the order system.

## Order Issues

For missing, delayed, or incorrect orders, the customer should provide their order ID so the order can be investigated.

## Order Cancellation

Cancellation availability depends on the current order status.

## Important

The AI assistant must not create, modify, cancel, or provide fabricated order information without confirmation from the order system.
